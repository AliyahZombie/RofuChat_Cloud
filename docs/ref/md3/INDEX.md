## How this was captured

m3.material.io is an Angular SPA. Each page's text was taken from the JSON the site itself loads to render the page (`/_dsm/content/m3/<version>/<pageId>.json`), and token tables from the site's design-token data modules (`/_dsm/data/dsdb-m3/<version>/TOKEN_TABLE.<id>.json`). A spot check against the rendered page (web_fetch of states/state-layers) matched word for word; the JSON route also yields the full token tables, which the rendered text only shows partially.

Conventions in the files:

- Images and videos appear as `*[Image: alt text]*` followed by their caption (captions often hold the numbered anatomy/measurement lists).
- Do / Don't / Caution items are block quotes: `> ✅ **Do**`, `> ❌ **Don't**`, `> ⚠️ **Caution**`, each with its caption text.
- Token tables: `Token | Name | References | Value`. References show the alias chain (e.g. `md.sys.color.primary → md.ref.palette.primary40`). Values are resolved for the baseline context (default contrast, 3P, Android, static font); where light/dark theme or standard/expressive motion differ, both are listed.
- The per-platform implementation-status tables (Android/Compose/Flutter/Web availability) are interactive widgets on the site and are not included; a placeholder line marks where they sit.

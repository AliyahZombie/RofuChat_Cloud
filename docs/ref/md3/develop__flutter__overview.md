# Flutter

## Material 3 Widget catalog

Flutter supports original M3 components. M3 Expressive is not available on Flutter.

> **Material Flutter widget catalog** (https://docs.flutter.dev/ui/widgets/material)
> The Flutter team is currently working on Material Design 3 support for Material Components.
